## 2. 验证方式

真实入口：在项目根运行 `python3 -B -m unittest -v`，无替身或外部服务。

| 输入 | 预期断言 |
| --- | --- |
| `"title"` | 返回 `"title"`，保留既有回归 |
| `"  title  "` | 返回 `"title"` |
| `"\t title\n"` | 返回 `"title"` |
| `"two  words"` | 返回原字符串，内部双空格不变 |
| `"  two  words  "` | 返回 `"two  words"`，同时覆盖裁剪与内部保留 |
| `""` | 抛 `ValueError`，且 `str(exception) == "empty title"` |
| `" \t\n"` | 抛 `ValueError`，且消息精确相同 |
