# 总设计 v3

交付依据为 [用户确认范围](../approved-scope.md)。当前 MVP 是单调用者本地 CSV 导出工具，已实现并验证完成。

`export_csv(path, rows)` 使用标准库 `csv.writer` 写入 UTF-8，支持中文、逗号、引号和单元格换行，空列表写空文件，同一路径覆盖，允许调用者指定有效绝对路径。

v2 由 Agent 自行加入的可信导出服务前置要求没有用户授权：取消输出目录限制、WriterRegistry、并发锁和永久失败封禁。这些并非本轮验收依赖；没有实现或作为待办保留。未来候选文件不在本轮范围，保持不变。

方案、验证与边界见 [CSV 子设计](designs/export.md)；当前状态见 [交接](handoff.md)。
