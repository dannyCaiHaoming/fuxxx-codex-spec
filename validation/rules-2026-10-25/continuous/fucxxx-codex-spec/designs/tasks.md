# MVP：持久化任务清单
依据：../design.md 与项目 README。
结果：add_task(path, title) 返回含 id/title 的 dict；list_tasks(path) 重新打开文件返回列表。
方案：标准库 pathlib/json，UTF-8、ensure_ascii=False；先 strip 和判空，再加载当前列表，以现有最大整数 id 加一，最后保存。
选择理由：当前只有本地文件存储，直接 JSON 足够验证真实持久化，插件加载器不帮助当前验收。
边界：顺序调用；并发写入、损坏文件恢复不在本轮；解析/文件系统错误原样暴露，不静默抹掉数据。id 类型未指定，采用正整数。
验收：原测试、现有文件空标题不改写、UTF-8 中文、跨进程增加和读取且 id 唯一。
状态：实现完成；原 2 项测试及新增 2 项测试在同一次最终运行全部通过。主会话核对接口、校验顺序与文件持久化；这是自检，不是独立评审。
证据：[验收记录](../evidence/tasks.md)。未覆盖并发写入、磁盘故障及损坏文件恢复，均不属于当前 README 契约。无当前 MVP 未完成项。
