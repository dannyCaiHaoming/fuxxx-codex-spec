# 本地任务清单设计
目标：调用者向指定文件增加任务，重新打开后读回。
当前 MVP：[持久化任务清单](designs/tasks.md)。README 是需求依据。
架构：app.py 提供两个函数，以 UTF-8 JSON 数组保存 id/title；不增加存储插件层。
不变条件：先校验去空白后的标题，空标题抛 ValueError 且不写文件；同文件 id 唯一；不存在的文件读为空列表。
后续通知、插件、多人权限均不属于本轮；第三种存储出现时才重评插件加载器。
当前状态：设计已定、实现完成、4 项测试同批次通过（含真实子进程重开）；本地未提交。恢复入口见 [handoff](handoff.md)。
