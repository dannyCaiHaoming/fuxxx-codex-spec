# 标题工具设计

目标：README 的两个独立函数可用，由两个独立内部子 Agent 分别实现，共享项目目录，主会话复核收口。

- `normalize_title(title)`：字符串 strip 后非空返回；空字符串或纯空白抛 ValueError。保留内部空格。
- `render_title(title)`：标准库 html.escape(title, quote=True) 转义 &、<、>、双引号和单引号，返回 str。独立于 normalize，保留空字符串及空白。
- 非字符串输入不新增契约。不引入插件、HTTP、配置系统或第三方依赖。
- 离线，只改本项目；不安装、commit、push。此目录不是 Git 仓库，以产物 SHA256 记录版本。
