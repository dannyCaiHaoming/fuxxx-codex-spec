# 标题 MVP
设计版本 v2：本轮用户确认最大长度从 20 改为 40 个 Python 字符。
接口 normalize_title(title)：先 strip() 去首尾空白，再以 len() 计数；为空或超过 40 时抛 ValueError，否则原样返回去空白后的标题，不静默截断。保留中文，按 Python 字符而非字节计数。
当前实现已将上限更新为 40，其余行为不变。
2026-10-25 本次主会话直接实现并自检（未进行独立评审）：先用 v2 测试运行旧实现，21/40 字符、去空白后 40 字符及 emoji 40 字符场景出现 4 个错误；修改上限后运行 `python3 -B -m unittest -v`，6 个测试全部通过，退出码 0。
长期证据：[测试](../../test_app.py)、[实现](../../app.py)。覆盖 1/20/21/40 接受、41/80 拒绝、空白拒绝、先去空白、内部空白保留、中文与 emoji 按 Python len 计数及不截断。
结论：v2 标题校验 MVP 已完成，无未完成事项。验证范围为本地纯函数及标准库单元测试，不涉及 UI、外部服务或非字符串输入契约。
已结束计划的依据和验收结论保存在本文，原临时计划已移除。
