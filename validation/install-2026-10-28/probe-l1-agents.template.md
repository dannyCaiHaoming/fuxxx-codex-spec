本项目采用 fucxxx-codex-spec。涉及设计、计划、实施、复核、恢复或收口时，
即使用户未点名，也使用该 Skill 分流；小修改只核对约束并修改、验证，
design／plan 按需建立。普通问答直接回答。
Skill 入口：{T}/pkgs/main/fucxxx-codex-spec/SKILL.md。
Skill 包根：无。
阶段能力入口：init {st}/fucxxx-codex-spec-init/SKILL.md；design {st}/fucxxx-codex-spec-design/SKILL.md；
  plan {st}/fucxxx-codex-spec-plan/SKILL.md。
项目资料根：fucxxx-codex-spec/。

- 开始相关工作时读 Skill 所需内容，按任务选读现存 handoff、索引、相关 design
  和活动 plan；已有明确派单时直接读指定资料。执行与恢复方法以 Skill 为准。
- 需要阶段能力时按上述登记位置解析并实际读取；读取成功才算已加载，
  解析不到就报告缺口。
